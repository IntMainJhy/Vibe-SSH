# Vibe-SSH 0.2.0 Beta 1

Vibe-SSH 是面向开发者和运维的开源 macOS SSH 客户端。用自己的终端连接服务器、浏览 SFTP 文件和查看 Linux 监控。也可以把部署交给 Codex，在同一个工作台看命令和输出，遇到问题随时接管。

## Beta 更新

- **日常连接**：OpenSSH 配置预览导入、密钥代理、多跳连接、免认证 HTTP CONNECT 和 SOCKS5、个人会话端口转发。跳板和目标分别核对主机指纹。
- **文件工作台**：直接访问 SFTP 根目录或账号主目录，使用路径导航。文件和文件夹支持双向传输与手动续传，目录比较可应用明确选中的新增或替换，保留原文件备份。
- **终端与监控**：查找、导出保留的终端文本，缩窗时仍能查看末行与底部操作。Linux 监控包含 CPU、内存、负载与磁盘挂载点用量。
- **Agent 部署**：Skill 与 CLI 随应用启动同步。批量计划按顺序执行并记录每一步的结果，失去控制权后停止提交后续步骤。任务历史保存有上限的原始输出，可分页查看和导出。
- **接管与升级**：关闭主机接入会撤销 Agent 的旧租约。升级保留本机服务器配置和历史，重启前未完成的任务按结果未知显示。CLI 与应用继续使用协议 v2。

## 验收与限制

已覆盖真实回环 OpenSSH、隔离 Debian 13、Apple 芯片 macOS 安装升级和 Intel 构建的 Rosetta 启动。Codex 使用安装后的 Skill 完成静态站点和 Compose 的部署、故障恢复和交接。Claude Code 的独立部署仍受模型网关 HTTP 403 阻塞。其他 Agent 的可用性取决于宿主的 Skill 支持和本地命令权限。

Beta 使用临时签名。Developer ID、Apple 公证、干净系统和物理 Intel 设备仍需补充验收。当前桌面安装包面向 macOS。欢迎提交[测试反馈](https://github.com/IntMainJhy/Vibe-SSH/issues/new/choose)，请包含版本、芯片、复现步骤，并移除连接凭据与敏感信息。

**English summary.** The public macOS Beta adds OpenSSH import and routing, resumable SFTP transfers, reviewed directory updates, and observable agent deployments with log export and human takeover. Download the DMG or ZIP for your Mac and verify it against the checksum file above.
