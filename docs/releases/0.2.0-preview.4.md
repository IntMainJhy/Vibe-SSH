Vibe-SSH 0.2.0 Preview 4 参考云集群工作台重做界面，保持黑白配色与日常 SSH 工具定位。

- 窄导航和轻量卡片，新增总览、服务器和会话视图。深色“继续工作”面板、会话列表及文件/监控快捷入口指向真实空间。
- 总览展示已配置服务器、已连接会话、运行中任务和允许 Agent 接入的服务器数；不推断未连接服务器的在线状态，不生成健康评分。搜索可匹配服务器与会话，失败提示直接定位对应任务。
- 会话保留对象侧栏、终端/文件/监控、接管和归还；监控趋势可切换 CPU/内存，仅使用打开页面期间实际取得的采样。深色资源面板突出当前使用率，运行时间作为辅助信息。
- Agent 活动提示改占独立底栏，保留全局流光并避免遮挡数据；窄视口收起重复上下文，保留输出、控制权、页签、搜索按钮和快捷键。支持浅色、深色与减少动态效果。
- 延续文本编辑、备份与冲突检查、SFTP 文件操作及 Skill/CLI 随应用启动同步。Agent 协议仍为 v2，没有新增内置模型或多 Agent 调度。

独立视觉复核为 8/10，已修复监控遮挡、失败状态截断、紧凑终端露出和监控主次问题。浏览器走查覆盖搜索、失败任务定位、接管、保存后读回、草稿保护、记忆页签及趋势切换；使用开发样例数据，不将其算作真实 SSH 或完整故障修复证据。发布流程另运行 Rust/前端检查与双架构构建。

macOS 提供 Apple 芯片 `arm64` 和 Intel `x86_64` 的 DMG/ZIP、SHA-256、安装说明及第三方声明。**仍为预览版**，使用临时签名，尚未通过 Developer ID 签名和 Apple 公证；Windows/Linux 桌面包、完整原生窗口/钥匙串人工验收、目录差异预览、任务持久记录、端口转发和跳板机仍待完成。文本保存的外部并发与硬链接备份边界继续遵循 [ADR 0004](https://github.com/IntMainJhy/Vibe-SSH/blob/main/docs/adr/0004-remote-text-editing.md)。
