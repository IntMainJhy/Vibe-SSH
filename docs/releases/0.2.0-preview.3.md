Vibe-SSH 0.2.0 Preview 3 在文件工作区加入远端文本查看与编辑，并将此前各开发分支的成果整合到 main。

- 从文件名或“查看 / 编辑”入口打开不超过 1 MiB 的 UTF-8 普通文本。显示目标服务器、路径、编辑状态及字节数，支持 Cmd/Ctrl+S；保留 BOM 和 LF/CRLF。混合换行仅支持预览。
- 保存前检查内容摘要、大小、修改时间、权限和属主。支持所需 OpenSSH 扩展时，在同目录写临时文件、保留隐藏备份，再替换目标；缺少扩展时只提供预览。
- 发现版本冲突或控制权变化时拒绝覆盖并保留草稿；重新读取和关闭前可复制草稿或确认丢弃。重复 Esc 不会跳过草稿确认，打开的文本也纳入退出保护。
- 保留黑白界面、终端 / 文件 / 监控、上传下载、Linux 资源监控、Agent 操作流光边框及随应用同步的 Skill / CLI。Agent 协议仍为 v2，没有新增 Agent 编辑命令或内置模型。

下载按 Apple 芯片 `arm64` / Intel `x86_64` 区分，提供 DMG、ZIP 和 SHA-256 校验。先把应用移到“应用程序”后运行，安装说明和第三方声明随包附带。

这是**预览版**：应用使用临时签名，尚未通过 Developer ID 签名或 Apple 公证。没有 Windows/Linux 桌面包。原生窗口、钥匙串及安装卸载的完整人工验收待补；目录差异预览、任务持久记录、端口转发与跳板机仍未完成。

版本检查与替换之间仍有外部进程竞态；硬链接备份不是不可变快照，不保证保留此后外部替换产生的版本。发布阶段失联时应保留草稿、核实远端结果，不自动重试。详细边界见 [ADR 0004](https://github.com/IntMainJhy/Vibe-SSH/blob/main/docs/adr/0004-remote-text-editing.md)。

验证：32 项 Rust 常规测试、6 项前端测试、格式及 Clippy 通过。真实临时 OpenSSH / Tauri 命令验证保存读回、备份、同秒同大小冲突、权限变化、删除、链接替换及控制权失效；Debian 回环虚拟机另验证中文路径和 BOM/CRLF。浏览器走查和截图使用开发样例数据，覆盖保存读回、失败后保留草稿、重复 Esc、焦点归还及 100% / 200% 下的关键区域，不作为真实 SSH 写入证据。
