Vibe-SSH 0.2.0 Preview 5 补齐原生核心流程验收，并增加 M3 目录差异预览与任务、输出历史，沿用黑白 SSH 工作台。

- 文件页新增“比较目录”：用原生选择器选项目，先看两端元数据和忽略项，再只对所选普通文件比较 SHA-256。明确区分相同、变化、独有、类型冲突、未校验与不支持；不自动同步、覆盖或删除。
- 默认排除秘密文件、依赖与构建目录，不遍历忽略目录和后代链接。每侧最多 1000 项、64 KiB 路径和深度 16；单文件 8 MiB、总内容 32 MiB，超限明确提示。CLI 新增 `diff`，项目内容由调用方读取，套接字不接受设备路径。
- 新增历史页与 CLI `history list/get`。SQLite 事务保存任务意图和结果，每路保留 64 KiB 原始输出尾部、总字节数和截断标识，最多 256 条终态记录；这不是全量审计日志。重启前未结束的任务保持未知，不恢复连接、租约或重放命令。
- Agent 不可读取个人历史或当前未授权主机的历史。数据库损坏、未知版本、写满或不可写时，在意图保存失败后不执行远端命令；完成记录异常不改写真实 SSH 结果。旧任务与租约在进程重启后失效。
- 原生窗口已验证主机录入、指纹核对、中文终端、上传下载、文本保存、并行使用、接管归还与退出保护；加密私钥口令在隔离真实 Keychain 中通过重启连接。补齐小窗口的历史布局、差异状态优先级和新终端标签可见性。

验证包含真实 OpenSSH、CLI 进程强制退出/重启、Tauri 参数桥、存储故障与真实 Debian 回归。独立结构、视觉和 UX 评审后完成主流程复验；浏览器开发数据不作为真实服务器证据。M3 追加原生窗口复验受 ScreenCaptureKit -3811 阻止，未宣称新功能的原生点击已通过；详细范围见[原生验收](https://github.com/IntMainJhy/Vibe-SSH/blob/main/docs/acceptance/2026-11-17-native.md)和[实现状态](https://github.com/IntMainJhy/Vibe-SSH/blob/main/docs/06-development-and-status.md)。

协议保持 v2，新增方法兼容旧调用；使用新命令需同步升级应用，Skill/CLI 随启动同步。历史 schema 1 不迁移主机和凭据，未知 schema 不覆盖，参见 [ADR 0006](https://github.com/IntMainJhy/Vibe-SSH/blob/main/docs/adr/0006-directory-diff-preview.md) / [ADR 0007](https://github.com/IntMainJhy/Vibe-SSH/blob/main/docs/adr/0007-task-history.md)。文本保存的外部并发边界仍见 ADR 0004。

提供 Apple 芯片 arm64、Intel x86_64 的 DMG/ZIP 和 SHA-256。**仍为预览版**，使用临时签名，未完成 Developer ID / Apple 公证及干净系统安装卸载验收。端口转发、跳板机、SSH-agent 认证、自动同步执行和完整日志不在此版本中；没有新增内置模型或多 Agent 调度。
