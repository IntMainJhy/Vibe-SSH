Vibe-SSH 0.2.0 Preview 1 把日常 SSH 与 Agent 操作放在同一个工作空间。

- 黑白界面，终端 / 文件 / 监控页面切换；Agent 运行时有全局流光边框和空间入口。
- SFTP 目录浏览、普通文件上传下载、多选上传、新建目录、重命名和删除文件/空目录。传输流式进行，支持取消；同名项目不静默覆盖，接管后的旧传输不能继续写入。
- Linux CPU、内存、交换空间、系统负载、运行时间及根分区用量。离开页面停止后续采样，无需安装远端服务。
- 首次启动及升级时自动同步 Skill 和 CLI，不再提供安装按钮；保留无关同名条目。
- 保持固定主机指纹、按空间隔离连接和内核租约接管机制，不内置模型或多 Agent 调度。

下载按 Apple 芯片 `arm64` / Intel `x86_64` 区分，提供 DMG、ZIP 和 SHA-256 校验。先把应用移到“应用程序”后运行。安装说明与第三方声明随包附带。

这是**预览版**：应用包使用临时签名，尚未通过 Developer ID 签名及 Apple 公证，系统可能阻止首次打开；请核对来源后使用系统“隐私与安全性”的单次允许流程。没有 Windows/Linux 桌面包。文本编辑冲突检测、目录差异预览、任务持久记录、端口转发与跳板机仍未完成，真实窗口/钥匙串/安装卸载的完整人工验收待补。没有宣称普遍提速。
