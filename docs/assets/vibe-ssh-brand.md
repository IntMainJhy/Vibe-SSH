# Vibe-SSH promotional artwork

Created on 2026-11-17 for the repository README, using editable SVG and browser-rendered PNG exports.

| Asset | Source | Export |
| --- | --- | --- |
| README banner | [vibe-ssh-hero.svg](vibe-ssh-hero.svg), 1600 × 840 | [vibe-ssh-hero.png](vibe-ssh-hero.png), 1600 × 840 |
| Application and promotional mark | [vibe-ssh-mark.svg](vibe-ssh-mark.svg), 512 × 512 viewBox | [vibe-ssh-mark.png](vibe-ssh-mark.png), 1024 × 1024, transparent |

Design brief: a centered white ceramic tile with two opposing graphite connection segments, a narrow blue seam and an abstract S-shaped passage; a broad blue halo fading from pale upper corners into midnight navy; quiet terminal, file-transfer and server outlines along the bottom. The composition references the supplied banner's visual hierarchy while using original Vibe-SSH artwork.

Exact copy:

> Vibe-SSH
>
> SSH for you and your AI.
>
> AI 操作，随时接管

The files are self-contained. The SVG text remains editable and uses local system fonts. PNG exports capture the reviewed typography for consistent display on repository hosts. The approved standalone mark also supplies the desktop bundle, Dock, navigation brand and browser favicon. Regenerate the macOS PNG/ICNS assets with `python3 scripts/generate-icons.py` on macOS after updating the source PNG. The banner describes external AI operation and human takeover without speed, ranking or award claims.
