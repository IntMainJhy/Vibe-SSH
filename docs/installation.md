# 安装 Vibe-SSH 预览版

Vibe-SSH 是日常 SSH 客户端，可由外部 Agent 通过 Skill 调用。当前提供 macOS 安装包；Linux 是已验证的远端服务器系统，不代表已有 Linux 桌面安装包。

1. 按芯片选择 `macos-arm64`（Apple 芯片）或 `macos-x86_64`（Intel）。下载发布页的 DMG 或 ZIP，并对照同页 `SHA256SUMS.txt` 校验。
2. 打开 DMG，把 `Vibe-SSH.app` 拖到“应用程序”；ZIP 解压后也应先移入“应用程序”。从该位置首次启动，避免在临时解压目录长期运行。
3. 预览版使用临时签名，尚无 Developer ID 签名与 Apple 公证。其他 Mac 可能拦截打开；核对来源和校验值后，按系统“隐私与安全性”中的“仍要打开”流程处理。不要关闭系统整体安全检查。正式分发仍待开发者证书与公证。
4. 添加服务器，填写地址、账号与认证方式，获取指纹并通过可信渠道核对后保存。默认不向 Agent 开启主机接入；需要使用时在服务器设置中逐台开启。

应用每次启动自动同步内嵌版本的 Skill 到 `~/.agents/skills/vibe-ssh`、`~/.claude/skills/vibe-ssh`，并创建 `~/.local/bin/vibe-ssh` 命令链接。无需在界面安装 Skill。无关同名条目会保留并在侧栏提示，不修改 shell 配置。若 Agent 的 PATH 不含该目录，可运行 `"$HOME/.local/bin/vibe-ssh" skill`。移动应用后重新启动即可修复属于 Vibe-SSH 的旧链接。

工作空间支持终端、SFTP 文件浏览与单文件上传下载、多选上传、目录管理，普通 UTF-8 文本预览/编辑与版本检查（最高 1 MiB），以及 Linux CPU、内存、交换空间、负载、运行时间和根分区用量。Agent 持有运行任务时显示黑白流光边框；可切到其他空间继续操作。上传同名文件不覆盖，取消或断线后先检查临时文件；目录批量同步由 CLI 的 `put` 提供。

卸载时先退出应用，再把应用移入废纸篓。主机配置位于 `~/.vibe-ssh/hosts.json`，密码/口令位于系统钥匙串的 `io.github.intmainjhy.vibe-ssh` 服务；卸载应用不自动删除这些资料。按需移除配置目录和该服务对应条目，以及属于 Vibe-SSH 的 Skill/CLI 链接；不要删除其他工具的同名内容。

这个版本仍是预览版：原生核心流程与隔离 Keychain 口令重启已有验收，目录差异预览和有界任务/输出历史已实现；M3 目录比较和历史重启读回也已完成原生点击复验；干净系统安装卸载、正式签名/公证仍未完成。跨进程原子文本冲突控制、端口转发、跳板机与 SSH-agent 认证仍在计划中。产品不内置模型或聊天服务。

升级会在首次任务/历史读取时创建 `~/.vibe-ssh/history.sqlite`（schema 1），主机 JSON 和钥匙串格式不变；旧版本没有任务历史可迁移。未知或损坏 schema 不会被覆盖，请保留数据目录并使用支持该版本的客户端。历史包含命令及有界输出，卸载时是否保留该目录由你决定；删除应用不等于清除历史。历史不恢复连接和租约，也不重新执行命令。
