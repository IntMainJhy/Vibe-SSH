# Vibe-SSH 正式版开发计划

当前基线为 macOS [0.2.0-beta.1 公开测试版](releases/0.2.0-beta.1.md)。M0–M4 验收继续沿用。本计划记录从 Beta 到稳定版需要的新增证据与交付门槛。

## 产品目标

交付一个可以每天使用的 SSH/SFTP 工作台，同时让外部 Agent 通过随应用启动同步的 Skill 调用同一个客户端。调用链为 Skill → 版本匹配的 `vibe-ssh` CLI → 本地套接字 → 应用内核 → SSH。连接、任务和控制权属于应用，用户能观察操作、切换页面、接管或中断。个人空间保持独立。客户端不内置模型、聊天、云端凭据托管或多 Agent 调度。

面向用户的入口是给现有 Agent 一句部署目标。已授权的连接和执行结果由客户端提供，Agent 可以通过一个结构化调用提交多个已知步骤。OpenSSH 可供 Agent 直接执行，属于端到端速度的强对照。对桌面工具需单独核实各自的脚本能力，并比较设置连接、交付任务、观察及接管各环节的操作，实测前只陈述已经验证的差异。

## 开发顺序与完成标准

| 顺序 | 交付内容 | 验收门槛 |
| --- | --- | --- |
| 1. 控制与接入 | 主机授权撤销；安装、升级、卸载；随包 Skill 发现和版本匹配 | AC-039 验证在途任务和旧租约；AC-030 在干净 macOS 安装包环境验收，升级保留主机和记录、不覆盖其他 Skill，卸载行为有记录 |
| 2. Agent 实际使用 | Codex、Claude Code 各自以已安装 Skill 部署；结构化的远端目录、受限文件读取和资源快照 | AC-033 各做一次首次上线、故障诊断与恢复；人工接管成功。记录命令次数和卡点。DeepSeek 按实际宿主单列验证；宿主须可发现 Skill 和执行本地 CLI |
| 3. 传统 SSH | OpenSSH 配置预览导入、`ssh-agent` 密钥认证、跳板机与代理、端口转发、本地连接与会话管理 | 人工选择导入和核对指纹，未知配置项明确提示；每跳独立验证指纹；验证本地、远端和动态转发的规则、绑定范围、关闭和断线行为。补齐终端内查找、快捷键和会话日志导出 |
| 4. 文件、监控与恢复 | 文件夹上传下载、传输队列及续传、权限编辑、多挂载点用量；显式差异应用和传输、部署记录 | 验证大小和内容、同名冲突、传输中断、符号链接、非 ASCII 路径和多挂载点；仅按显式选择应用差异，未知结果核验后再操作，记录保留与清除可控 |
| 5. 原生性能与发行 | 原生冷启动、目录、终端、大文件和长任务验证；签名、公证、两种架构发布 | 通过[交付验收](05-delivery-and-acceptance.md)，安装包在干净设备验证。报告测量条件和边界，公开版只声明已验证能力 |

SSH 认证代理用于使用用户已有的密钥服务；是否支持向远端转发密钥代理是单独的决定。配置导入不执行 `ProxyCommand` 或本地 Shell，不替用户信任新主机。端口转发从桌面人工配置起步，不自动成为 Agent 权限。Windows 与 Linux 桌面不作为首个 macOS 正式版门槛。

单文件和文件夹都支持上传、下载与显式续传。客户端可逐项确认并应用目录差异，历史保存桌面传输与 Agent 批量部署的结果。终端查找使用当前缓冲区。任务原始日志可从历史归档分页读取并导出，归档限额和恢复状态见 ADR 0007。

## Agent 接口设计

- 先采集 AC-033 中真实重复的步骤，再按使用频次补接口。文件、监控等读取使用有界输出和结构化错误，不接受 Agent 提供的任意本机路径，也不把远端输出当作指令。
- 读写复用同一任务空间连接。所有 Agent 写操作仍需在提交边界验证租约；不提供绕过客户端控制的远端通道。失败、取消、失联和结果未知分别处理。
- 每增加一个 CLI 方法，同步更新协议、内置 Skill 和真实套接字测试。可以复用内核文件与监控能力，保持桌面目录选择器、主机管理、信任和人工接管仅在客户端。

## 性能验收

先按 [性能评估方法](05-delivery-and-acceptance.md#性能评估)建立基线，再定目标。同一项目、服务端状态和 Agent 配置分别执行 Vibe-SSH 与开启连接复用的 OpenSSH 方案，交替运行并记录成功率、总耗时、工具调用次数、输出字节和人工介入。单独记录模型耗时、连接握手、远端构建和传输，不混为工具开销。

原生客户端分别测首窗就绪、5000 项目录可交互、终端输入延迟、长输出下的内存峰值，以及固定网络延迟下的 SFTP 吞吐。保留原始样本、构建版本、设备、网络和数据规模。现有回环命令和浏览器目录两组基线只用于各自的对照。
