| 版本 | 发布方式 | 功能范围 |

| 个人版 Beta | 公开源码与 macOS 安装包，现有代码继续采用 MIT | SSH、SFTP、资源监控、端口转发、外部 Agent Skill/CLI、批量部署、任务历史和日志、人工接管。公开仓库维护全部个人版实现。 |

已发布的个人版许可和功能范围继续有效。Pro 增量在独立工作区开发与分发，沿用基础组件的许可声明。公开仓库中的路线图与官网展示版本状态。试点、定价、授权交付和商业安装包另行验收。

## 首个可验证切片

### 发布模板

- 用户可保存一份现有 `batch` JSON 为本地模板。每份由模板标识、显示名称、正整数版本和有序步骤组成。已保存版本只读，修改时创建新版本。
- 模板支持已有的命令执行与文件上传。上传源相对于本次选择的项目目录，运行前拒绝路径越界和符号链接入口。纯命令模板无需选择项目目录。命令保留为用户声明并核对的字面内容。
- 每次运行前选择已启用 Agent 接入的主机，并核对版本、目标、命令和上传路径。现有批量执行器开启独立空间并校验租约，失败、接管或结果未知时停止提交后续步骤。模板不会自行触发执行。
- 模板存于应用本地资料目录，和主机配置、钥匙串、任务历史分开。模板不含凭据字段，避免在命令中填写明文凭据。

### 交付报告

- 在部署历史中导出 UTF-8 Markdown。报告记录发布标识、模板名与版本（如果来自模板）、目标主机显示名、开始时间、耗时、整体状态和各步骤的类型、状态、退出码和关联记录标识。运行中导出标明是当前快照，未知与跳过分别展示。
- 导出直接读取本地任务记录。只包含列出的结构化字段，省去命令正文、原始日志、连接地址、凭据和租约。用户在桌面确认保存路径，取消不生成文件。
- 历史数据库与 Agent 套接字协议仍沿用个人版。首个切片在单个客户端上工作，后续团队共享使用独立配置与授权设计。服务器凭据由原客户端保管在本机。

## 验收顺序

1. 无效模板和越界上传源在创建 SSH 空间前拒绝；同一版本不能被覆盖，重启可重新选择旧版本。
2. 临时 OpenSSH 上复用已存在的批量执行协议，成功上传后运行验收命令；失败时验证后续步骤停止。接管与租约检查沿用原有执行器，并复跑现有真实套接字用例。
3. 从成功或中止的真实部署记录导出报告，逐项核对状态、跳过项和关联记录。验证报告字段约束以及 Markdown 中用户可编辑文字的转义。
4. 本地验证 Pro 桌面入口、模板创建和确认、历史报告预览与导出。对外发布前复验签名、升级、定价和授权交付。

## 当前开发状态

首个切片已在本地 Pro 预览版实现。回环 OpenSSH 验证覆盖相对路径上传、成功归档、失败后停止、后续步骤跳过和原有租约检查。macOS 原生窗口已验证保存模板、核对发布、从部署历史预览报告和取消保存，Markdown 内容及文件写入由自动化用例验证。

公开提供下载的是个人版 Beta。企业版 Pro 的定价、授权、签名与商业安装包仍待验收。

## 后续切片

先验证团队是否反复复用模板。之后设计生产审批和权限策略，明确哪些路径在内核执行审批。团队共享需单独设计共享边界、成员权限和自托管历史，不改变凭据留在本机的约定。
