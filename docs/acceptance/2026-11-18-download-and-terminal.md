# 2026-11-18 原生下载与终端工具验收

用 Apple Silicon macOS 27.2 和临时签名的 Tauri 应用包复验。应用资料、SSH 密钥和远端文件由测试夹具生成。所有 SSH 服务在回环地址。保存位置为原生保存面板中临时创建、验收后清理的独立目录。

| 操作 | 实际结果 |
| --- | --- |
| 原生文件页选择中文文件，保存并暂停 | 128 MiB 文件在写入 68,386,816 字节后暂停，传输面板显示 65.3 MiB，目标文件尚未发布 |
| 重启原生应用，连接原服务器并点击继续下载 | 重启后显示等待续传，连接后恢复到完成；下载内容与服务端文件逐字节一致，SHA-256 为 `254bcc3fc4f27172636df4bf32de9f107f620d559b20d760197e452b97453917` |
| 终端查找 | 在真实 CLI 任务的只读输出中查询不存在的文本，显示未找到。查询中文字符串并触发上一个和下一个，收起查找后仍可操作当前任务 |
| 原生导出 | 保存的 104 字节文本为 UTF-8，含中英文输出的原始逻辑换行，逐行读回符合预期；再次启动保存面板并取消 |
| 动态转发 | 最终候选包的转发面板选择动态 SOCKS5，分配回环端口。系统 curl 通过该代理读回临时 HTTP 正文，点击停止后规则从面板移除 |

OpenSSH 集成测试另覆盖原大小和时间戳下的远端内容变化，同名目标冲突与重启读回。原生通过按钮路径验证查找，`⌘F` 与 Esc 的物理键盘路径需继续复验。
