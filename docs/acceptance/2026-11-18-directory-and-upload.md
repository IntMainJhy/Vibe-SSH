# macOS 原生目录差异、上传续传与远端转发验收

2026-11-18，在 Apple Silicon 上用本地构建的候选应用、系统文件面板及临时回环 OpenSSH 服务验收。每轮使用独立应用资料、临时 SSH 主机和身份密钥，服务地址为 `127.0.0.1`。

| 验收项 | 操作及结果 |
| --- | --- |
| AC-046 目录应用 | 在文件页用系统面板选择项目目录，勾选一条子目录内的二进制文件和一条已有的中文配置文件。确认页列出两条路径和预定动作。提交后两份服务器文件逐字节与项目一致，原配置留有可读取的备份，权限 `0640` 保留。未选文件、忽略项和服务器独有文件未受影响。 |
| AC-047 上传续传 | 通过系统面板选中 512 MiB 的 `重启续传.bin`，暂停时服务器临时文件为 156663808 字节，最终路径尚未生成。退出后重启，续传按钮在未连接时禁用。重新连接并手动继续后应用显示完成，服务器文件与源文件 SHA-256 一致，临时文件与续传队列清理。 |
| AC-048 传输历史 | 通过原生面板上传并下载同一个 21 字节的中文文件，源文件、服务器文件和下载文件逐字节一致。重启应用后，无需重新连接即可在历史页读取两条完成记录和服务器路径。集成用例另验证未结束的记录重启后标记为未知，以及 Agent 无法读取人工传输记录。 |
| AC-041 远端转发 | 从个人会话创建远端转发规则，由 sshd 分配监听端口，连接客户端回环 HTTP 服务。经分配的端口取得 HTTP 200 和预期正文。点击停止后规则消失，端口拒绝连接。 |

自动化回环验收覆盖同大小内容变化、清单跨控制代次失效和重复提交拒绝，另覆盖错误服务器、源文件变化、同名目标、临时文件前缀篡改、符号链接与临时文件缺失。消失的临时文件不会被续传自动重建。
