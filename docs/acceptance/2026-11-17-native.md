# macOS 原生端到端验收

环境：2026-11-17，macOS arm64，Tauri 真实 WebView，preview.4 基线。使用 `python3 scripts/native-acceptance.py` 创建独立应用副本、临时数据/集成目录、临时密钥和随机回环端口的系统 OpenSSH。未读取用户 SSH 配置、主机、钥匙串或真实服务器，用户原有应用与空间保持运行。

通过原生可访问性控件、键盘和系统文件选择器执行操作；没有用前端模拟数据或直接调用 Tauri command 代替点击。远端文件由测试夹具独立读回，Agent 断言通过应用自身的 CLI 发出。

| 项目 | 实际结果 |
| --- | --- |
| AC-019 | 空白主机列表进入添加表单；探测到的 SHA256 与临时 host.pub 独立计算一致；核对后保存，点击连接成功 |
| 终端中文 | 新建第二个终端后，原生粘贴 `echo 原生终端_OK > native-input.txt`，远端精确读回 16 字节。测试服务必须显式设 UTF-8 locale；macOS 默认 C locale 下 Shell 会把中文按 Meta 键解释 |
| AC-014 | 原生个人空间包含两个活动终端时，Agent `space list` 仍为空 |
| AC-021 | Agent 空间执行 300 秒任务时切回个人终端，写入 `parallel-input.txt` 并独立读回中文内容 |
| AC-022 | 原生界面接管，旧租约返回 CONTROL_REVOKED，无远端副作用；归还后旧租约返回 STALE_LEASE，新租约执行成功 |
| 上传 | NSOpenPanel 选择含中文、空格的 21 字节临时文件，界面显示传输完成，SFTP 目标逐字节一致 |
| 文本保存 | 打开中文文件，编辑后保存；原生界面显示已保存及备份位置，远端新内容正确、备份为原始 13 字节内容 |
| 下载 | NSSavePanel 保存文本，界面显示完成，所得 16 字节文件与远端一致。首次把绝对路径填入 Save As 时，macOS 将斜线转为文件名中的冒号；此行为不作为目录导航的验收 |
| AC-023 | Cmd+Q 显示 3 个活动任务的退出确认；继续运行后任务仍可见；再次确认后仅验收应用退出，用户原应用仍运行 |

自动化曾遇到 ScreenCaptureKit -3811 / -3812，重置控制会话并重新选择验收应用后恢复。窗口快照偶尔仅返回缩略视图，未据此声称完成像素级原生视觉验收。

AC-020 口令切片：显式编译 `cargo build -p vibe-ssh-desktop --release --features native-acceptance,tauri/custom-protocol`，再用 `python3 scripts/native-acceptance.py --binary target/release/vibe-ssh-desktop` 启动。原生表单保存加密私钥口令到临时真实 macOS Keychain；确认条目存在，配置文件无口令；首次连接成功，经 Cmd+Q 确认退出后，在夹具根创建 `restart.request`，重新打开主机且不重填口令，连接成功。安全文本框须原生粘贴，AX setValue 未产生输入；未保存时认证失败可见，实际保存后恢复。密码 SSH 认证的协议证据见既有 Linux 验收；此次原生重启实际使用加密私钥。

测试钥匙串与正式版采用相同服务/账户语义，但明确指定临时 Keychain，脚本退出会清理。正式发行包不启用 `native-acceptance`；没有访问用户现有登录钥匙串。
