# 文件夹续传、部署记录与兼容性验收

2026-11-18。本轮使用临时 SSH 服务器与应用资料目录，固定主机指纹后连接。用户的 SSH 配置和真实服务器不参与验收。

| 项目 | 验证结果 |
| --- | --- |
| AC-049 文件夹续传 | 真实回环 OpenSSH 上，上传和下载都在第一个文件块后停止。重新创建服务、连接同一主机并读取已保存计划，确认为从 32,768 字节继续。逐字节核对最终内容与空目录。另验证同名、前缀改动和符号链接都阻止发布。桌面命令桥验证待续传列表、双向续传与记录清理。 |
| AC-050 批量部署 | 真实 CLI 测试验证命令、上传、校验、退出码 7 和未提交步骤。接管后后续步骤不执行，归还后旧租约仍失效。在打包后的 arm64 客户端，用内置 CLI 生成部署记录并读回每项状态。 |
| AC-050 归档日志 | 用真实 CLI 产生超过 1 MiB 的输出，重启服务后按页读回完整首尾、中文和无效 UTF-8。打包 arm64 客户端生成 1,300,000 字节正文加中文首尾，原始文件逐字节相符。桌面命令桥读取私有记录并核对完整标志。 |
| AC-051 代理与兼容性 | 独立回环 HTTP CONNECT 和 SOCKS5 代理验证指纹探测、实际远端命令、错误指纹及代理拒绝。三项隔离 Debian 13 集成测试通过。arm64 和 x86_64 应用均本地构建并验证临时签名。x86_64 应用与内置 CLI 在 Apple Silicon 的 Rosetta 下完成真实 SSH、批量任务和日志读回。 |

原生窗口已打开，锁屏阻止了文件选择器、继续传输按钮及日志保存面板的点击验收。物理 Intel 和干净 macOS 的完整安装验收仍待独立环境。归档每路 64 MiB，总配额 512 MiB。代理验收覆盖免认证模式。[日志设计](../adr/0007-task-history.md#任务日志文件) · [连接设计](../adr/0011-jump-host-and-local-forward.md#出站代理)
