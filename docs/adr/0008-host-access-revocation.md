# ADR 0008 主机授权撤销

状态：正式版首个开发切片。补充 [ADR 0002](0002-task-spaces-and-agent-neutrality.md)。

## 行为

关闭 Agent 接入或删除主机并保存成功后，已有 Agent 空间由用户持有。新空间申请和新的远端差异扫描被拒绝；旧空间的任务输出仍可观察。已提交的操作无法撤回，命令不会因为撤销自动被杀，用户可以人工中断或关闭。上传后续帧和结束帧同样校验租约；已写入的部分可能留在服务器。

重新打开接入不自动归还。只有用户明确归还才签发新租约；此前空间的旧租约永不恢复。用户个人空间及其他授权主机不受影响。

## 串行化

保存主机清单时获取受影响空间的控制锁，配置写入成功后，更新控制权、租约并通知观察者，再确认保存。写入失败保留原授权。SSH 握手不占用主机配置锁；握手完成后对比开始时的配置代次，拒绝在配置变更前发起的 Agent 开启请求，包括关闭再开启期间的旧握手。主机配置以客户端的保存操作为授权变更入口。

协议保持 v2，没有新方法、数据结构或持久迁移。新开、归还和远端差异扫描在主机未授权时返回既有 `HOST_NOT_AUTHORIZED`。旧空间写入返回 `CONTROL_REVOKED`；以后显式归还后，旧租约返回 `STALE_LEASE`。已开始的读取或已经交给 SSH 的数据无法收回；活跃任务输出的可见范围与当前主机授权过滤的归档历史是两套规则。
