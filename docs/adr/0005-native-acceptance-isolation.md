# ADR 0005：原生验收的凭据隔离

状态：接受。日期：2026-11-17。

原生界面验收不能读写开发者的真实主机、SSH 配置和钥匙串。脚本创建临时密钥、回环 sshd、数据目录、集成目录和独立应用副本；普通发行构建仍使用原有系统钥匙串服务和账户，不改变凭据格式。

桌面凭据操作集中在一个适配器中。仅显式启用 `native-acceptance` Cargo feature 的开发构建可使用临时真实 macOS 钥匙串，且启动必须找到验收根标记和匹配的数据、集成目录，否则退出；不暴露额外套接字接口。发行工作流不启用此 feature。

验收脚本仅清理其创建的进程、文件和临时钥匙串。重启测试保留该临时钥匙串与主机元数据，验证应用重新连接；配置文件不得出现口令。该证据覆盖相同适配器的原生交互及真实 Keychain 持久性，不代表已访问或验证用户现有登录钥匙串项目。
