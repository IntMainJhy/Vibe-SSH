# ADR 0006：只读目录差异预览

状态：接受。日期：2026-11-17。

M3 新增目录比较，不自动同步、覆盖或删除。先列元数据及忽略项，再由调用方明确选择普通文件计算 SHA-256；未选择、忽略、符号链接和特殊文件不读取内容。相同大小或时间不能证明内容相同。

CLI 在自身进程扫描、读取它获准访问的目录，将有界清单及所选摘要发送给服务；Agent 套接字不接受客户端设备路径。桌面通过原生目录选择器获得路径，以随机令牌保存在可信壳中，只接受该令牌和已列出的相对文件名。Agent 只能比较自己的空间；个人空间仍不可见。比较不取得写权限，接管和归还不因读取而改变。

每侧最多 1000 项、相对路径合计 64 KiB、深度 16；超限明确返回截断。只哈希每个不超过 8 MiB、总计不超过 32 MiB 的所选普通文件；超限项标为未校验。默认排除 `.git`、`node_modules`、`target`、`dist`、`.ssh`、`.env*`、`*.pem`、`*.key`、`*.p12`，附加规则为单路径分量的 glob，不宣称兼容 gitignore。忽略目录只显示该目录，不遍历后代。

远端通过空间独立的 SFTP 读取元数据，只有两侧都为普通文件且提供所选摘要才读取远端内容。根路径明确解析，扫描不跟随后代链接；读取前后检查命名项目与句柄元数据。存在外部进程并发修改时属于有界乐观快照，不承诺远端原子目录快照或抵御同一 SSH 账户的恶意竞态。无法读取、链接和截断均有显式状态；本次预览不是后续写入的授权或版本条件。

协议 v2 新增 `diff` 只读方法，旧调用兼容；新 CLI 连接旧服务会得到明确不支持的方法错误，应更新应用。结果不含设备绝对路径。Skill 仅在实现后列出命令。
