# ADR 0003 完整 SSH 工作台与自动接入配置

日期：2026-11-17。状态：按用户明确要求实施，修订 ADR 0002 的手动 Skill 安装决定。

Vibe-SSH 是可分发的日常 SSH 客户端，同时为外部 Agent 提供确定性执行入口。界面采用黑白设计，不以“本机专用”描述产品；凭据与 IPC 的设备安全边界保持不变。不增加模型、聊天或多 Agent 调度。

应用启动后自动同步内嵌版本的引导 Skill 和 CLI 链接，不再提供安装按钮。安装位置仍是当前系统用户的 Agent 目录，不修改 shell 配置；无关的同名内容不覆盖，配置失败在界面可见。测试使用独立临时用户目录。

每个空间在原有独立 SSH 连接上按需复用一个 SFTP 通道。文件浏览、上传、下载和目录管理由桌面人工入口调用，不把设备文件选择或下载路径加入 Agent 套接字。Agent 继续使用已有 tar 流上传，设备文件由调用方读取。上传使用临时文件、逐块控制代次检查和不覆盖的 SFTP rename；取消、接管或断线不自动重试，未发布的临时文件可能保留供核实。下载流式写入用户选择位置的临时文件，成功后才发布。首切片不承诺目录同步、覆盖编辑的跨进程原子冲突检查。

资源监控只对当前可见监控页按需采样，复用该空间连接，离开页面停止下一轮采样；从 Linux /proc 和 df 获取 CPU 差值、可用内存、交换空间、负载与根分区占用。不安装远端守护程序，不使用 sudo，不把采样写入任务历史。非 Linux 远端明确报告不支持。

Agent 仍在运行时，应用外沿显示黑白流光及可跳回的空间入口；切换页面仅改变观察对象，不关闭任务。减少动态效果偏好下使用静态边框。

Agent 协议保持 v2，无不兼容修改。发布先提供标注平台与签名限制的预览版，不把未验收的编辑器、跳板机、端口转发或跨平台支持宣称为已完成。
