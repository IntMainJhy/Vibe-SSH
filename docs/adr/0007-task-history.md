# ADR 0007：有界任务与输出记录

状态：接受。日期：2026-11-17。

任务历史与活动空间分离，历史 ID 不可作为 job、cursor 或 lease。SQLite schema 1 保存任务元数据与每路最多 64 KiB 原始输出尾部（保留总字节数、截断/无效 UTF-8 标识）；运行内存仍每路 1 MiB。为首个有界切片采用同一事务中的 BLOB，替代架构草案中分离输出文件的计划，避免摘要成功而输出文件未发布的交叉一致性问题。未来完整日志或产物采用单独文件，不能将当前尾部记录宣称为全量审计。

每个 home 持有内核文件锁，SQLite 操作在 blocking 线程执行。schema 不支持、损坏、被占用或不可写时明确报错，不覆盖数据库，不在无法写入任务意图时发出远端执行；schema 1 不迁移既有主机 JSON 或凭据。未来 schema 迁移须先备份并事务执行。文件权限 0600、目录 0700；不保存输入、密钥或租约，命令及输出仍可能含敏感业务数据，应按用户数据保护。

在发送 exec/shell 前提交任务意图；提交超时记录未知，不自动重放。输出由独立任务最多约每秒快照一次，SSH 读取不等待磁盘；完成时提交终态和尾部，再通知完成。写入失败保留真实 SSH 结果，显示记录失败。突然断电/强制退出可丢失最后约一秒或尚未提交的输出；启动将残留 running 记录改为 unknown/client_restarted，不能推断远端失败。

最多保留 256 个终态记录和 256 个未结束意图；未结束意图达到上限时，在远端执行前拒绝新任务。SQLite 主文件设 96 MiB 页数上限，事务失败可见；回滚日志另有临时开销。空间关闭和内存淘汰不删除历史；历史自动淘汰不改变远端任务。首个切片不提供清除接口。

桌面可以查看个人与 Agent 记录。Agent 只读历史接口仅返回 Agent 来源且主机目前仍存在、允许 Agent 接入的记录；历史输出不构成授权。列表有界分页，详情只返回请求的尾部。协议 v2 增加 history_list/history_get；旧方法兼容，新命令需更新应用。正式版不提供凭据和人工控制方法。

桌面文件传输在 schema 1 的记录元数据 JSON 中追加可选 `transfer` 字段，包含方向、服务器路径与已知的文件大小。既有命令记录可继续读取。用户发起的传输按个人记录处理，在接管的任务空间内也保持个人可见性。续传的每次尝试单独记录，结果未知时不会自动续传。传输历史 I/O 失败由状态界面报告，传输回执按真实操作结果返回。

## 任务日志文件

新终端和远端任务分别归档 SSH 收到的原始 stdout/stderr，PTY 保留合并流。磁盘归档不改变实时缓冲或历史尾部。每路最多 64 MiB，全部归档共用 512 MiB 配额，随历史记录淘汰清理。中断、写入失败和配额不足会标出保存长度及不完整状态。任务结果继续取自 SSH。

使用 0700 目录和 0600 文件。桌面可把归档原始字节保存到用户选定的位置，Agent 只能按页读取当前获授权主机的 Agent 来源记录。进程重启后可读已落盘前缀；旧记录继续显示原有输出尾部。日志不记录键盘输入流或密钥。远端程序可能回显自己收到的内容。

依赖固定 rusqlite 0.43（bundled SQLite），最低 Rust 1.89，与项目声明一致，参见[上游 Cargo 配置](https://docs.rs/crate/rusqlite/0.43.0/source/Cargo.toml.orig)。
