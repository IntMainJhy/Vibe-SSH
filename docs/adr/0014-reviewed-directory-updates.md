# ADR 0014 应用所选目录差异

桌面在完整比较中为已校验的新增和修改文件生成一次性应用清单。清单保存选定内容的 SHA-256、目标目录和空间的控制代次。用户核对新增和替换后确认。应用前重新读取已选本地内容并复核远端版本，按文件提交并返回成功路径和备份位置。缺失的父目录可随新增文件创建。

文件先写入同目录临时文件。新增用拒绝覆盖的重命名，替换依赖服务器的 OpenSSH 原子重命名和硬链接备份。替换前确认内容和元数据版本，保留权限和属主，并读回确认。SFTP 无法与其他进程的写入建立同一事务。独立进程可在版本检查与重命名之间改动路径。应用保留可用的备份和可核实的状态，收到不确定回执时停止。

不包含删除、目录替换或双向同步。符号链接、特殊文件、忽略项、截断比较和超出哈希预算的文件均不能应用。每次远端写入复核控制代次。套接字协议继续提供只读方向的 diff。
