# ADR 0009 Agent 的结构化远端读取

正式版第二个开发切片。Codex 部署验收中反复通过 `run` 读取目录和文件；把这些观察动作接入已有 SSH 连接，以统一的 JSON 返回数据，不创建命令任务或历史记录。

- `files list <space> [path] --limit N`：通过 SFTP 读取一层目录，默认 `.` 和 100 项，最多 1000 项及 64 KiB 的元数据预算。返回 `path`、`entries`、`truncated`。排序只针对已读条目，截断不是完整列表，也不能证明某路径不存在。跟随目录入口时返回实际远端路径；条目里的链接按链接列出，不递归。
- `files read <space> <path> --max-bytes N`：只读调用方明确指定的一个远端普通 UTF-8 文件，默认 8192 字节，最多 65536 字节。超限、二进制或末级符号链接返回错误，不自动转读其他路径。允许经目录别名访问同一普通文件；SFTP v3 的元数据检查不能替代原子快照。返回路径、字节数和内容，不产生桌面编辑令牌。
- `resources <space>`：复用固定 Linux 采样脚本，不接收自定义命令，不安装组件或提升权限。一次采样约 1 秒，返回 CPU、内存、交换空间、负载、运行时间和根分区用量。每空间同一时间最多一个样本，复用桌面采样约束。

读取必须使用 Agent 空间，主机当前须允许 Agent 接入；人工接管本身只限制写入。套接字只能指定远端路径，不读取本机文件。不覆盖 Agent 的既有账号权限或用户授予的任务范围。内容是非可信数据；仅按任务所需显式读取，避免凭据和无关文件。

保持协议 v2；新增 `files_list`、`files_read`、`resources`，旧 CLI 不受影响，新命令需随应用升级。`status.capabilities` 宣告这些方法；没有持久数据格式变化。较旧服务会拒绝不了解的方法，不能把这类拒绝当作文件不存在。
