# ADR 0010 OpenSSH 配置预览与本地密钥代理

OpenSSH 配置只由用户通过桌面选择器打开。最多读取 256 KiB UTF-8 普通文件；解析内容不会执行命令、读取 Include、解析环境变量或接触已知主机文件。显式 Host 别名产生候选；常用 `Host` 模式可以提供默认值，连接字段采用最先命中的有效配置。预览列出未支持的指令名称和行号；连接路由、认证或信任相关配置不能假装已导入。导入一个候选仅填表，不发网络请求或保存。用户要核对指纹，Agent 接入默认关闭。参考 [OpenSSH 配置手册](https://man.openbsd.org/ssh_config)。

主机资料增加可选 `ssh_agent` 布尔值，缺省为 false。它是手动选择的认证方式，与密码或私钥文件互斥。本地密钥代理读取客户端进程的 `SSH_AUTH_SOCK`，仅在服务器指纹通过后询问和使用本地密钥；每次连接试用至多 6 个普通公钥。不向远端转发代理，不把密钥或套接字路径暴露给 AI Agent。命令行套接字协议保持 v2，既有主机无需迁移；启用此认证的资料需用支持该字段的客户端打开。
