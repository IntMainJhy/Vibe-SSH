# ADR 0012 文件夹传输

桌面文件页支持显式选择一个本地文件夹上传，或选中一个远端文件夹下载。按 SFTP 递归遍历，保留目录结构和空目录，最多 5000 个条目、16 层；拒绝符号链接、特殊文件和不安全路径。远端写入每一步检查启动传输时的控制代次，包括创建目录、单文件发布和最终目录重命名。一个空间同一时间只有一个文件操作。

上传先写到目标目录中的唯一临时目录，完成后以 SFTP 不覆盖重命名发布。失败时保留临时路径供核实。下载在用户选择的本地父目录下创建新目录，已存在则拒绝；失败可能保留部分目录，单文件下载后才发布。进度按完成的条目显示，文件内容不进入 WebView 或 Agent IPC。下载不改变远端。断点续传、自动应用差异和持久传输记录另行验收。

## 双向续传

新传输先保存私有计划，绑定主机身份、两端路径和源目录的版本清单。上传和下载都使用同目录私有临时树。重启后由用户在原主机主动继续，复查整个源清单，对已完成文件或部分文件按字节复核，再从通过校验的偏移读写。树和路径有界，符号链接、特殊文件、计划外临时条目和同名最终目标都会停止当前尝试。

上传每次写入复核控制代次，下载使用本地无覆盖重命名发布。SFTP 的版本证据受服务器提供的元数据粒度限制，额外进程若同秒改写且保持元数据，只能通过已传前缀发现。发布回执缺失后先核实最终目标，缺少临时树时不会自动重建。放弃续传会清除记录，保留临时目录供用户核实。
