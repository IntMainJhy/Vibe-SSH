# ADR 0015 单文件上传续传

桌面选择一个普通文件时，先保存一份最多 32 条的本地待续传队列，记录服务器身份与指纹、目标路径、随机临时文件标识和本地文件版本。记录以用户私有权限写入，凭据和空间租约不进入磁盘。首轮上传检查创建计划时的控制代次。恢复由用户在原服务器且持有控制权的会话里主动发起。

临时文件与目标位于同一服务器目录。恢复前检查目标尚未存在、临时文件为权限 0600 的普通文件、本地文件标识与时间戳相符，并逐字节核对已上传的前缀。随后从通过验证的偏移追加，发布前再次检查源文件版本、临时文件和目标目录。每次远端写入检查当前控制代次，最终使用拒绝覆盖的 SFTP 重命名。

目标已出现、临时文件缺失或内容变化时，保留当前数据与记录，提示检查。远端结果未知时不会自动重放。放弃续传只移除本地记录，服务器临时文件可通过文件工作台另行管理。多文件选择仍逐个上传，文件夹传输另行实现断点恢复。
