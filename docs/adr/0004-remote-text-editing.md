# ADR 0004 远端文本编辑与版本检查

日期：2026-11-17。状态：按 M3 / AC-024 实施。

桌面文件页增加 UTF-8 普通文本文件预览与编辑。每份文本上限 1 MiB，拒绝二进制、符号链接及特殊文件。读取生成受空间和控制代次约束的版本；内核仅保留每空间最近 8 份的摘要与元数据，不保存文本草稿到磁盘。版本不是授权，保存仍须检查空间控制权。

保存先核对 SHA-256 内容摘要、大小、修改时间、权限和属主，再写同目录的独占临时文件。逐块写入、元数据更新、备份和发布都检查原控制代次，归还/重新接管不能恢复旧草稿的写权限。支持 OpenSSH hardlink 与 posix-rename 扩展时，保留原文件的隐藏备份，核对版本后原子替换目标，保留权限与属主。缺少所需扩展时只提供预览，不退化为直接截断写入。一次服务内编辑保存串行，避免客户端自己的并行保存相互覆盖。

外部进程并不遵守客户端的锁：版本检查和 rename 之间仍有竞态窗口，不能宣称跨进程的原子 compare-and-swap 或文件系统事务。备份保留创建备份时的原 inode，不保证保留此后外部 rename 引入的版本，用户可查看备份路径；不自动删除备份或重放结果未知的保存。硬链接备份会跟随同 inode 上的外部原地写入，这不是不可变快照。常规的保存前内容修改、同秒同大小修改、权限变化、删除和链接替换均须拒绝覆盖。

界面用黑白编辑面板，显示未保存状态、UTF-8 字节数与保存结果。冲突后保留草稿，可复制草稿或明确重新读取；取消未保存编辑需要确认。离开编辑器不自动保存。接管按钮仍在空间头部，Agent 控制期间只允许预览。

打开文档的数量仅存在于桌面快照和原生退出保护，不从 Agent status 返回。只增加桌面人工命令，不增加 Agent 套接字方法。Agent 协议仍为 v2；新增 FILE_CHANGED 是桌面保存冲突的错误码。现有 CLI、Skill 执行接口不变，说明同步更新。
