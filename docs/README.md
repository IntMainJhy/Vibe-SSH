# Vibe-SSH 方案总览

日期：2026-11-16。版本：设计基线 0.1。阶段：M0 内核验证。

本方案将 Vibe-SSH 定义为可由外部 Codex 高效操作的桌面 SSH 客户端。服务器由用户手动添加，操作在本机内核中统一执行，客户端提供真实输出和可执行的接管动作。

“企业级项目”的要求落实为明确的模块边界、版本化契约、可追溯决策、故障语义、测试证据和发布门槛。企业多租户、集中管控和高可用服务器不属于首版范围。

## 已确定的决定

1. 用户像使用 FinalShell 一样手动填写服务器资料。
2. Vibe-SSH 不内置推理 Agent，Codex 通过 Skill 与 CLI 操作。
3. Rust 内核统一管理 SSH 连接、任务、输出和控制权。
4. UI 使用 Tauri 2、React/TypeScript 和 xterm.js。
5. 优先复用协议库与终端组件，不整体 fork 一个完整 SSH 客户端。
6. 首版先验证 Linux/POSIX 远端；桌面目标为 macOS 和 Windows。
7. M0 使用本地临时 SSH 服务验证，不依赖真实生产凭据。
