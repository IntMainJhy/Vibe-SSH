# Vibe-SSH 交付与验收计划

## 交付原则

每个里程碑产生可运行切片和可复现证据。进度由完成的验收项决定，不用创建目录、写完设计或依赖安装成功代替功能完成。

本计划使用 M0 至 M4 推进首版，M1 至 M3 的顺序已按 [ADR 0002](adr/0002-task-spaces-and-agent-neutrality.md) 调整。涉及真实服务器的验收由用户提供专门测试主机与授权后执行；开发默认使用本机临时 SSH 服务。

## M0 内核验证

目标：验证选定 SSH 底座、结构化结果、PTY 和输入权设计，形成可运行的 Rust 基础。

| 验收项 | 必须观察到的行为 |
| --- | --- |
| AC-001 主机身份 | 正确固定指纹连接成功，错误指纹在认证前被拒绝 |
| AC-002 执行结果 | stdout、stderr、非零退出码和尾部数据被正确保留 |
| AC-003 缺失退出码 | 通道结束但无退出状态时返回未知 |
| AC-004 连接复用 | 同一已认证连接上的多个通道完成操作，未重复握手 |
| AC-005 PTY | 请求终端、接收真实输出、发送输入和尺寸变化 |
| AC-006 接管 | 人工接管成功后，旧 AI 令牌写入被拒绝 |
| AC-007 归还 | 归还后仍拒绝旧令牌，新令牌可以操作 |
| AC-008 输出预算 | 大输出受限，游标与截断标识准确，UTF-8 不损坏 |
| AC-009 SFTP | 临时测试目录中写入与读取结果一致 |

M0 不要求桌面 UI、持久主机管理或系统凭据存储已完成。实验命令只能标注为开发验证入口。

## M1 Agent 闭环

目标：任意 Agent 通过 Skill 和 CLI 操作用户已配置的主机；内核按任务空间隔离并强制控制权。此阶段没有界面，主机来自用户手写的配置文件。

交付常驻服务、当前用户专属的本地套接字、任务空间、原生 CLI、增量输出、上传、控制权切换和引导式 Skill。

| 验收项 | 必须观察到的行为 |
| --- | --- |
| AC-010 空间隔离 | 每个空间一条连接；一个空间断线，其他空间继续工作 |
| AC-011 主机授权 | Agent 只能列出和打开用户开启接入的主机 |
| AC-012 接管 | 接管确认后，Agent 的输入、新任务、上传、中断和关闭全部被拒绝；进程不被终止 |
| AC-013 归还与交接 | 归还后旧租约仍被拒绝，新租约可用；Agent 可主动交接并附原因 |
| AC-014 用户空间 | 用户自己的空间对 Agent 不可见、不可写，不能交给 Agent |
| AC-015 增量等待 | 长任务先返回运行中，凭游标继续读取，不重复执行；等待到期不是失败 |
| AC-016 真实互操作 | 经真实 OpenSSH 服务完成执行、PTY 输入、中断、上传和加密私钥认证 |
| AC-017 版本与实例 | 协议版本不符、服务未运行、旧实例标识都得到明确错误 |
| AC-018 Skill 安装 | 安装不覆盖无关的同名内容 |
| AC-032 Linux 互操作 | 在真实 Linux 服务器上完成执行、信号、PTY、上传、中断、并发上限、接管、三种凭据和 sudo 交接 |

## M2 macOS 桌面应用

目标：用户无需 Agent 也能正常使用 SSH，并能观看和接管 Agent 的空间。

交付 Tauri 外壳、手动添加主机、指纹核对、系统钥匙串、多标签终端、Agent 空间的实时观看、接管与归还、自动 Skill/CLI 配置与冲突提示。

| 验收项 | 必须观察到的行为 |
| --- | --- |
| AC-019 界面配置 | 用户全程通过界面添加主机并核对指纹，不编辑配置文件 |
| AC-020 凭据 | 密码与私钥口令保存在系统钥匙串，重启后可用，配置文件中没有秘密 |
| AC-021 并行使用 | Agent 正在执行时，用户的终端输入不受影响 |
| AC-022 界面接管 | 界面接管后 Agent 被拒绝，归还后用新租约继续 |
| AC-023 退出提示 | 有任务在运行时退出应用会先提示 |
| AC-031 同一命令 | 应用本身就是 `vibe-ssh` 命令，应用启动自动同步 Skill 与命令，保留无关同名条目并提示异常 |
| AC-034 桌面可用性 | 可搜索服务器与会话、手动重连、调整外观和字号；错误可见，模态框可用键盘操作，长文本输入不超预算且旧队列不重放 |

## M3 文件与项目

目标：完整的文件策略。

交付文件浏览与下载、文本编辑与冲突检查、同步差异预览、任务与输出的持久记录。AC-024：覆盖前验证版本条件。AC-025：大目录、非 ASCII 路径和符号链接按明确策略处理。AC-026：秘密文件与忽略规则可预览，未选择的路径不被读取。

文本编辑当前切片：AC-024 的内容与元数据版本检查、冲突拒绝和原文件备份已有真实 OpenSSH / Linux 证据；不承诺任意外部写进程下的原子 CAS，详见 ADR 0004。目录差异预览与持久记录仍待完成。

新增文件与监控切片验收：

- AC-035：SFTP 上传读回一致；同名文件不覆盖；取消、接管与旧租约不发布半成品；特殊路径、符号链接与 5000 项目录上限有真实 SSH 证据。
- AC-036：Linux CPU、内存、交换空间和根分区来自真实远端；采样失败可见；离开页面不再排下一轮。
- AC-037：空间内终端、文件、监控可切换，保留页签与目录；新终端自动切到可输入区域；Agent 活动边框不阻塞导航；启动不需要安装 Skill 按钮。

## M4 部署与首版发布

目标：两种参考项目可部署、可诊断、可验证，并具备安装包交付证据。

静态站点验证构建、上传、Nginx 配置校验和 URL 访问。Compose 项目验证同步、构建、启动、健康检查及失败日志。应用版本恢复明确支持范围，数据库变更不伪装成可自动撤回。

AC-027：干净测试主机上完成首次部署。AC-028：重复部署相同项目不会无故重复创建服务。AC-029：故意制造配置错误和健康失败，有明确诊断，并能恢复到最后可用版本。AC-030：macOS 安装、卸载及基本使用完成记录。AC-033：由真实 Agent（Codex、Claude Code）仅凭 Skill 独立完成一次部署。

## 验证层次

| 层次 | 验证对象 | 示例 |
| --- | --- | --- |
| 领域测试 | 控制权、状态、输出预算 | 旧 epoch、游标轮换、缺失退出码 |
| SSH 集成 | 真实协议连接与通道 | 临时密钥、回环服务、执行与 PTY |
| 本地进程集成 | CLI 和内核 | 端点权限、版本、取消与重连 |
| 界面验证 | 人工输入与观察 | 中文、尺寸、标签、接管竞态 |
| 部署验收 | 完整业务结果 | 服务健康、URL、失败诊断 |

临时测试服务只监听回环地址，使用随机端口与临时密钥，不修改系统 sshd、用户 known_hosts 或真实服务器。

## 性能评估

设两条基线：固定命令脚本验证工具开销；相同 Agent 配置验证完整任务交互。直接 OpenSSH 基线也开启合理的连接复用与批处理，避免只与低效使用方式比较。

记录冷启动与热运行的 p50/p95、CLI 启动、本地 IPC、握手、通道创建、总任务耗时、业务调用次数、输出字节、人工介入和成功率。远端构建、依赖缓存与网络条件分开记录。

重复测试使用相同项目、可复原服务器状态和交替顺序，说明缓存影响。先收集基线再设提速目标，不预先宣传倍速。优化不能降低输出完整性、主机验证或接管正确性。

## CI 与发布门槛

Rust 切片检查格式、Clippy 和测试，当前在 macOS 上构建和验证，发布流程分别构建 Apple 芯片与 Intel 包。前端加入后补类型检查、构建和关键交互验证。网络相关集成使用本机服务，减少外部依赖。

正式首版须通过：全部 P0 验收、安装包验证、凭据和主机信任验证、接管并发验证、数据迁移与恢复验证，以及未解决问题清单。阻塞问题不能以“企业级”命名掩盖。

每次交付说明已实现能力、验证命令、实际结果、尚未覆盖的平台和下一阶段入口。

## 初始风险与应对

| 风险 | 影响 | 应对与决策点 |
| --- | --- | --- |
| russh 与特殊服务器不兼容 | 无法连接用户主机 | M0 验证常用认证和通道，复杂兼容留到明确需求 |
| 原生加密依赖增加打包成本 | 平台构建失败 | 提前验证目标工具链，锁定特性与版本 |
| PTY 与结构化执行混淆 | 假成功或错误接管 | 分开两类路径，缺失状态返回未知 |
| 用户与 AI 并发写 | 扰乱远端命令 | 内核串行化和 epoch 拒绝旧请求 |
| 断线后自动重放 | 重复修改或部署 | 结果未知先查证，单独记录恢复动作 |
| 日志无限增长 | 内存和磁盘耗尽 | 字节预算、轮换、过期游标语义 |
| 实际提速不明显 | 产品价值不足 | 与优化过的 OpenSSH 对照，优先减少 Agent 往返 |
| 产品许可证未确定 | 后续发布路线受影响 | 发布前确定自有许可与第三方清单 |
