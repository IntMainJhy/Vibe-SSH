## 文件相邻目录分栏（preview.5 发布后）

文件页从单表格改为左右两栏：左侧保留上级目录与选中项，右侧展示下级目录；继续选择右栏中的项目时，将已加载目录复用为左栏，避免重复读取。普通文件显示信息与查看/编辑、下载入口。两栏独立滚动，选中背景沿用黑白过渡；上传、新建与比较针对底部注明的当前目录，重命名仍在所选项目的父目录完成。右栏读取失败保留父级列表，切换或离开后忽略旧响应；比较窗口固定打开时的目标，不被后台刷新改写。

浏览器开发数据验证覆盖多级进入、上级返回、新建、重命名与删除、文本保存后重新打开、比较目标路径、只读操作禁用、读取失败后切换同级目录，以及下级请求逆序返回后的选择隔离。检查了常规窗口、880×560、小窗口等效放大阅读与深色模式；此记录不代替原生窗口或真实 SFTP 的新增端到端证据。本轮未修改内核、协议或 Skill。

类型检查、6 项前端测试、生产前端与原生 release 编译通过。新增分栏仍通过现有人工桥读取目录与管理文件；浏览器传输验收确认上传指向所选目录、下载指向所选文件，系统选择器和实际传输沿用此前原生验收边界。

## 0.2.0-preview.5 M3 目录差异与历史

先完成[原生验收](acceptance/2026-11-17-native.md)，再实现 M3 剩余两项。桌面文件页新增原生目录选择入口，先列两端元数据与忽略项，再只哈希明确选择的普通文件；路径相同、大小相同不等于内容相同。CLI `diff` 在调用方读项目，服务只接收有界清单；个人空间对 Agent 不可见。默认秘密文件、依赖和构建目录不读内容，不遍历忽略目录或后代链接。每侧 1000 项 / 64 KiB 路径 / 深度 16，单文件 8 MiB、总内容 32 MiB，截断不会伪装成完整比较，预算与竞态见 ADR 0006。此切片只预览，不自动同步或删除。

主导航新增历史页，CLI 新增 `history list/get`。schema 1 SQLite 在 exec/shell 前保存意图，独立快照输出，保存终态后公布；最多 256 条终态与 256 条活动意图，每路保留 64 KiB 原始尾部及总字节数。命令最多保留 8 KiB，列表缩为 512 B。重启前未结束意图为 unknown/client_restarted，旧 job/cursor/lease 无效，不恢复连接或重放。Agent 只可看 Agent 来源且当前主机仍允许接入的历史；个人记录只在人工桥可见。存储锁、权限、版本、磁盘上限与失败语义见 ADR 0007。

证据：真实 OpenSSH 的目录比较覆盖相同、同大小不同内容、独有项、类型冲突、中文特殊路径、链接、不可读的忽略/未选文件与截断；真实 CLI 进程强制退出后重启，读回输出、保留未知、拒绝旧标识，远端副作用计数仍为一次。数据库损坏、未知 schema、第二个写入者、SQLITE_FULL、只读失败与 Unicode 尾部有针对性测试；意图保存失败时远端文件不产生。Tauri MockRuntime 通过前端参数形状调用真实 SSH 的比较和历史命令，验证人工历史不经 Agent 接口泄露、空间关闭后历史仍可读。真实 Debian 再次验证执行、PTY、凭据、文件、资源和所选内容哈希。

沿用黑白工作台和原生 Modal，不做视觉换向。完成独立结构、视觉和 UX 各一轮（存量扩展不打分），修正小窗口的历史上下文、差异结论优先级，以及新建终端后的当前标签可见性。使用既有按钮按下、Modal 淡入和选择背景过渡，减少动态效果规则不变。浏览器画面与功能验证使用开发数据，不能代替真实服务器证据。M3 追加原生复验曾受 ScreenCaptureKit -3811 阻止；候选应用重启并重连自动化后恢复，已完成真实系统目录选择、所选哈希、忽略状态、历史两路输出和再次重启的未知记录读回。实际点击范围见原生验收记录；候选与 arm64 打包副本使用同一编译产物；对临时副本去除不同签名后，编译内容 SHA-256 一致。

## 0.2.0-preview.2 工作空间切片

按用户要求将产品完善为可分发的日常 SSH 客户端，Agent 通过 Skill 使用确定性内核。依据 [ADR 0003](adr/0003-desktop-files-and-onboarding.md) 开发，黑白设计替换早期蓝灰基线，界面不再强调特定设备，也不再有安装 Skill 按钮。

已实现：终端 / 文件 / 监控页签，空间记忆页签与目录，新建终端自动进入；全局 Agent 流光边框和返回入口，支持减少动态效果，切换空间不关闭任务。SFTP 文件浏览、多选单文件上传、单文件下载、新建目录、重命名、删除文件或空目录；流式传输进度和取消在切页后保留，既有同名项目不覆盖。目录最多 5000 项并受字节预算限制。上传中途失去控制权不发布临时文件；旧租约不恢复。文件类型使用精确模式判断，不能把符号链接视为普通文件。

Linux 监控读取 `/proc/stat` 差值、`MemAvailable`、交换空间、负载、运行时间与 `df -Pk /`；只在可见监控页继续轮询，不安装远端服务。实际采样已在 Debian 13 验证；非 Linux 返回明确错误而非零指标。

应用启动自动同步引导 Skill 与 CLI 链接，不更改 shell 配置，不覆盖无关同名目录或悬空链接。发布构建已在临时数据和接入目录中真实启动，自动生成两个 Agent 目录链接与 CLI，并通过该 CLI 完成回环 SSH 执行和关闭空间。应用移动后的自有链接可更新。设备文件选择和保存路径只在桌面人工桥接中使用，Agent 套接字保持 v2。

验证：30 项常规 Rust 测试通过，另有 2 项 Linux 测试必须显式启用（原先 Linux CLI 测试的未启用情况改成真正 ignored，避免将跳过计成通过）。文件测试含真实 OpenSSH 的内容读回、引号和中文路径、符号链接拒绝、同名保护、空文件、5000 项目录预算、取消、接管与旧租约。Tauri MockRuntime 命令调用真实 sshd 验证目录管理、只读与控制权。Debian 上资源采样另单独执行。前端 4 项输入队列测试、类型检查、构建、Rust 格式与 Clippy 通过。浏览器使用样例数据检查新建目录后刷新读回、跨页保留目录、新终端自动切页；不把模拟传输视为真实上传证据。

独立视觉与 UX 检查各一轮（存量扩展不打分），修正主操作反差、失败识别、监控空图过高，以及文件页创建终端后无可见反馈的问题。真实原生选择对话框、钥匙串和安装卸载人工验收仍待补充。

### 本轮桌面工作台与可用性改进（2026-11-17）

产品仍是日常 SSH 客户端，外部 Agent 可以通过 Skill 操作，不新增多 Agent 管理功能。设计说明见 [DESIGN.md](../DESIGN.md)。

- 新工作台以服务器列表和当前会话为主；新增服务器/会话搜索、明确的连接忙碌状态、手动重连、浅色/深色/跟随系统、终端字号记忆、复制完整命令、清空本地显示。
- 接管和交还保持在会话头部，终端区明确区分可输入与只读。关闭会话后回到工作台，不自动切到另一台服务器。断线后的重连新建个人终端，不重放任何旧命令。
- 服务器表单改用原生模态对话框，支持焦点约束、Escape 关闭与焦点归还；前后端都拒绝端口 0，前端还校验整数和 65535 上限。获取指纹时不能修改目标地址，避免把旧请求的指纹保存给新地址。
- 快照读取串行合并，避免旧响应覆盖新状态；启动失败显示错误与重试入口。服务器没有活动输出时也定期更新连接状态。
- 终端长文本按 Unicode 边界分成每块不超过 16 KiB 的输入。输入失败后丢弃后续队列，控制权变化前排队的输入不会在重新接管后恢复。输出读取失败有可见错误，并可只重读输出，不重放命令。stdout/stderr 分别增量解码，避免分包破坏中文。
- 原生关闭窗口与应用菜单/Cmd+Q 共用退出确认。菜单使用普通动作取代 macOS 的直接退出动作，有任务时先显示对话框；真实窗口里的退出操作仍待人工验收。
- 终端按需加载，主界面和终端分别构建，不再产生单个超过 500 kB 的构建分块警告。

本轮验证：4 项前端测试通过（多语言大文本分块、控制权丢失时停止队列、输入部分送达后不重试、跨控制权周期不恢复旧输入）；28 项 Rust 常规测试及显式启用的 1 项 Debian 虚拟机测试通过；前端类型检查/生产构建、Rust 格式与 Clippy 通过。

浏览器使用开发专用示例数据实际操作过：搜索、添加服务器、非法端口、指纹核对后保存、接管与交还、字号调整、Escape 与焦点恢复、手动重连、启动失败、连接失败、输出读取失败。1200×800 及应用最小窗口 880×560 下终端有可用高度，页面无横向溢出。示例数据仅在开发模式载入，不进入正式构建；截图与交付说明单独注明样例数据。

本轮发布版应用另在临时数据目录和回环 sshd 下启动，通过该应用自身的 CLI 完成开会话、执行命令、上传与读回文件、关闭会话；界面加载日志无脚本错误。原生窗口自动化在取得画面时被系统 ScreenCaptureKit 拒绝，未通过脚本或其他方式绕过；真实窗口点击、钥匙串和 Cmd+Q 的完整体验仍未据此宣称已验收。本轮不访问用户的真实主机配置、SSH 配置、钥匙串或 Agent Skill 安装目录。

- 构建产物原先只有链接器给可执行文件的临时签名，整个应用包通不过 `codesign --verify --strict`。现在构建时对整个包做临时签名，校验通过。它仍然没有开发者签名和公证，`spctl` 的评估结果是拒绝，拷到别的 Mac 上会被系统拦截。
- 数据目录放在“桌面”这类受系统隐私保护的文件夹里时，应用启动会卡在等待授权上，窗口不出现。默认的 `~/.vibe-ssh` 不受影响。

| AC-029 失败处理 | 静态站点：写坏配置后 `nginx -t` 失败，任务失败且未重载，站点继续提供原内容。Compose：新版本健康检查失败，任务失败并给出容器状态与日志；此时线上已是坏版本，按指南从 `current` 恢复后上一个版本重新健康 | 构建失败、数据库迁移 |
| AC-033 真实 Agent | 没有。全部命令由脚本或我直接执行，Codex 与 Claude Code 没有凭 Skill 独立完成过部署 | 整项 |

跑指南时发现并修正的问题，都已写回 Skill：非登录 Shell 的 `PATH` 里没有 `/usr/sbin`；探测脚本在组件缺失时以失败状态结束；占位符 `ID` 与 `/etc/os-release` 的 `$ID` 冲突；重载后立刻检查会读到旧进程的响应，需要按内容重试；不固定 Compose 项目名时每个发布目录会启动一份新的应用；`compose logs` 即使加 `--ansi never` 每行也带终端转义码；连接关闭时仍在输出的任务和 PTY 任务会被服务器终止。

回环夹具通过真实 SSH 协议通信，但远端命令是固定响应。OpenSSH 测试使用系统自带的 `/usr/sbin/sshd`，以当前用户身份监听回环随机端口，使用临时密钥，不读取用户的 SSH 配置，结束时终止进程并删除临时目录；它的远端 Shell 是 macOS 的。

Linux 测试服务器是 QEMU 加 Apple 虚拟化运行的 Debian 13 官方云镜像（下载后校验 SHA-512），只监听本机回环地址。登录密钥、测试密码和服务器的主机密钥都在 `target/vm` 里生成，主机密钥在首次启动时注入，所以指纹在第一次连接之前就已知，不存在“先连上再信任”。脚本不读写 `~/.ssh`。它是真实的 Linux，但不是公网服务器：没有网络延迟、丢包、防火墙和云厂商环境。

## 构建与运行

```sh
cd apps/desktop
npm ci
npx tauri build
open ../../target/release/bundle/macos/Vibe-SSH.app
```

应用包整体做了临时签名，没有开发者签名和公证；可作为预览包分发，其他设备首次打开可能被系统阻止，处理方式见[安装说明](installation.md)。数据目录是 `~/.vibe-ssh`（可用 `VIBE_SSH_HOME` 改变）：`hosts.json` 保存主机，`agent.sock` 是 Agent 入口。密码和私钥口令在系统钥匙串里，服务名 `io.github.intmainjhy.vibe-ssh`。

应用首次启动及升级会自动把 Skill 链接到 `~/.agents/skills` 和 `~/.claude/skills`，并把应用自身链接为 `~/.local/bin/vibe-ssh`。之后 Agent 的用法见 `vibe-ssh skill`，协议见[外部 Agent 协议](03-agent-protocol.md)。

开发界面时 `npm run dev` 可在浏览器里用示例数据预览，示例数据不进入正式构建。开发时可用 `VIBE_SSH_INTEGRATION_HOME` 把自动接入目标隔离到临时目录，默认仍为当前用户主目录。

不带界面运行内核用 `cargo run -p vibe-ssh-cli -- serve`，它只支持未加密的私钥。

## 已知限制

- 应用窗口关闭即退出，所有空间和连接随之结束；没有托盘常驻。
- 用 `VIBE_SSH_HOME` 把数据目录指到“桌面”“文稿”等受隐私保护的文件夹时，应用启动会卡住；私钥文件放在这些文件夹里时，首次读取会弹出系统授权。
- 任务与输出只在内存中，应用退出即丢失。
- 主机的 Agent 接入开关控制新建会话；已打开的会话需单独接管或关闭。
- 同一系统用户下的进程都能读到 Agent 空间的当前租约；租约防过期请求，不防其他本机进程。
- 通过标准输入提交的多行脚本在远端作为一个任务运行，接管不能阻止已在运行的脚本的后续行。
- CLI 目录上传依赖远端 `tar` 并会覆盖归档内同路径文件；桌面已实现 SFTP 浏览与普通文件上传下载，同名不覆盖。文本编辑已加入版本检查与备份；跨进程原子 CAS、目录差异预览尚未实现。
- 界面里用户的终端只有登录 Shell；Agent 的非终端任务输出按原样显示，不解析进度。
- 部署流程只在 Debian 13 上验证过；其他发行版的包名和配置路径需要 Agent 先探测再调整。HTTPS 证书、DNS 和云防火墙不在流程内。
- 已有回环空命令基线；尚无公网与完整 Agent 任务的提速结论。
- CI 只覆盖 macOS，不运行 Linux 虚拟机测试。
- 连接断开时，仍在输出的远端任务和 PTY 任务会被服务器终止；需要脱离连接运行的任务目前靠 Agent 按指南用 `nohup setsid` 启动，工具本身没有内置支持。
- 锁文件含上游引入的预发布加密依赖，正式发布前需要确认。
