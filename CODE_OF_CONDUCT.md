# Community code of conduct

This policy applies to Vibe-SSH issues, pull requests, discussions and project-related reviews.

## Expected behavior

Treat contributors with respect, explain technical disagreements with evidence, and give feedback about the work rather than the person. Welcome questions across experience levels and languages. Respect contributors' time and privacy.

Harassment, discriminatory abuse, threats, sexualized comments, deliberate disruption and publishing private information are not acceptable. Credentials and private server data must not be posted, even when reporting a defect.

## Moderation and reporting

For a public moderation problem, mention `@IntMainJhy` in the affected repository thread without repeating abusive or private material. Use GitHub's reporting tools for sensitive abuse or content that should not be reposted. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

The maintainer may ask for a correction, hide or remove content, lock a conversation, or restrict participation. The response should match the severity and repetition of the behavior. Good-faith technical disagreement is welcome.
